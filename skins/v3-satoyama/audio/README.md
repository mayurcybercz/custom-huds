# SATOYAMA recordings (optional)

Run `npm run fetch-audio` to download these into this folder. They're kept out of git; without them the skin uses synthesised sound (and has no children's voices).

| File | Used for | Source | Licence |
|------|----------|--------|---------|
| `children.mp3` | Children playing in the village square (very quiet, daytime only; a 75-second mono excerpt is used) | ["Kids Playing at Playground November 11 2020"](https://freesound.org/people/kvgarlic/sounds/545873/) by kvgarlic | CC0 |
| `bell.mp3` | The temple bell (bonshō) at 6:00, 12:00, 18:00 and on click | ["Montbell (Bonshō) von Japan"](https://freesound.org/people/Vurca/sounds/397352/) by Vurca, recorded at Hida no Sato near Takayama | CC0 |

Both are Freesound's public preview encodings of the CC0 originals.
